# Next physical test: sloped 2×1 lap-pin prototype

Print `output/sloped_lap_prototype/prototype_2x1_ALL_COMPONENTS_A1.stl` at 100% without auto-arranging. The layout contains two board halves, eight vertical T-pin variants, and four blank tile variants. It occupies 167.4 × 161.0 × 12.2 mm on the 256 × 256 mm A1 plate.

Recommended orientation: both board halves flat-base-down with sockets up; pins with their flat T-heads on the plate and shafts vertical; blank tiles flat. Start with no brim. Add a 2 mm brim only to pins if adhesion requires it. The sloped tabs are predicted near-support-free; inspect the local circular-bore bridges in Bambu Studio before printing.
