Git workflow

This repository should be kept under version control continuously.

After completing a coherent task or validated change:

run the relevant validation/tests first;
review the diff;
commit the completed change automatically;
use a concise, descriptive commit message;
do not wait for me to explicitly ask for a commit;
do not commit obviously broken, incomplete, or failing work;
if a task contains multiple unrelated changes, split them into separate logical commits;
do not force-push or rewrite existing history unless I explicitly ask;
do not push to GitHub unless the task explicitly asks for a push, unless we later decide to enable automatic pushing for this repository too.

Prefer commit messages such as:

Add sloped lap-pin prototype

Standardize 38 mm board chassis

Add A1 placement validation

Generate Blender sandbox exports
