# Current production boards

Use one board folder here for printable production quadrants. These are the only current board chassis assets. Print orientations are baked into each STL.

- `Akala/`, `Melemele/`, `Poni/`, and `Ulaula/` contain the four current quadrants for each board.
- `fit_test/` contains the universal socket/tile fit coupon; print it before creating a tile library.

Use historical assets only when a task explicitly asks for a historical prototype.
